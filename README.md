# Momentum Coach — Multilingual Fitness Website

React/Vite portfolio project for a personal trainer selling 1:1 coaching, small groups, cohort programs and digital guides.

## Languages
- English
- Polish
- Ukrainian

## Features
- Dashboard-style hero instead of a standard oversized landing page
- Dark mode
- Responsive navigation
- Personal and group coaching offers
- Live discount countdown
- Interactive before/after sliders
- Progress roadmap
- Digital fitness guides
- Trainer profile
- FAQ accordion
- Sticky consultation CTA
- Consultation modal

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

The demo uses remote Unsplash images. Replace them with your own licensed photos before commercial use.


## Transformation visuals

The before/after cards use original fictional SVG client visuals created for this demo. They do not represent real people or real medical/fitness claims.
